# Kitchen Curator

Local-first recipe collection and cooking companion for macOS.

## Initial version (v0.1.0)

- Save and edit recipes with ingredients and instructions
- Search the recipe library
- Build shopping lists
- Store recipes locally using SQLite
- Desktop interface foundation for Intel and Apple Silicon Macs

## Planned next features

- Import recipes from cooking-video descriptions, captions, and recipe pages
- Review extracted quantities and steps before saving
- Meal suggestions and weekly planning
- Consolidated shopping lists and pantry inventory

## Development status

**Early prototype.** macOS installer builds and runtime tests are not yet verified. The initial source archive must be imported into this repository before automated builds can run.

Kitchen Curator is a separate project from Music Video Curator. Do not commit personal recipes, API credentials, or local database files.
